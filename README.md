# PocketSec

Find out how hackable you are in 60 seconds. The scan runs in your browser.

**Score: 63 / 100** on the [ShipItWorks rubric](https://shipitworks.com/how-we-score/). Stage: Beta. As of 2026-11-02, from the [product page](https://shipitworks.com/apps/#pocketsec).
